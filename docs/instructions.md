## שער ראשון: ממשק הניתוב המרכזי וניהול בסיס הנתונים

עם הפעלת התוכנית, המערכת מבצעת תהליך אתחול אוטומטי המבוסס על קשר ישיר מול השירות `DatabaseManager`. תהליך זה טוען בצורה סדרתית את כל המידע מבסיס הנתונים אל זיכרון הריצה של המערכת דרך השירותים השונים, תוך שמירה על סדר תלויות קשיח: ראשית נטענים מוצרים ומיקומים עצמאיים, לאחר מכן משאיות, ספקים וסניפים, ולבסוף בקשות והובלות מורכבות.

לאחר סיום הטעינה, המשתמש מועבר אל תפריט הבחירה הראשי המהווה את שער הכניסה המרכזי של האפליקציה ומציע אפשרויות ניתוב ברורות:
1. **מערכת הובלות ולוגיסטיקה:** ניתוב למחלקה `AdminConsole` המנהלת את כל מערך ההובלות, המשאיות והספקים.
2. **מערכת ניהול עובדים ומשמרות:** ניתוב למחלקה `ServiceControl` המפעילה את תשתית המשמרות, שיבוץ עובדים והגדרת אילוצים.
3. **מחיקת נתוני מערכת מלאה (Wipe DB):** פונקציית מנהל מערכת המבצעת קריאה ל-`clearDatabase`, מכבה אילוצי מפתחות זרים, מוחקת את המידע מכל הטבלאות (כולל טבלאות קשר כמו `SupplierAllocation`), ומאפסת מונים אוטומטיים ב-SQLite. פעולה זו כופה יציאה מיידית מהתוכנית כדי למנוע חוסר סנכרון מול הזיכרון.
4. **יציאה מהתוכנית:** סגירת קלט המשתמש וסיום ריצת התוכנית בצורה נקייה.

## חלק 1: הוראות הפעלה – מערכת ניהול עובדים ומשמרות (`ServiceControl`)

### 1. תחילת עבודה ואתחול
עם הכניסה לרכיב זה, המערכת מבצעת טעינת נתונים פנימית ומציגה שאלה לגבי טעינת נתוני בדיקה מובנים מראש (`Preset Data`):
`"Enter true to load preset data and false to enter without"`

* **הקשת `true`:** תטען למערכת נהג (Marko, מזהה 10), שני עובדים (מזהים 11, 12), וכן הגדרות משרה ושיבוצים לדוגמה למחרת היום.
* **הקשת `false`:** כניסה למערכת נקייה ללא נתונים ראשוניים.

### 2. ניווט בתפריט העובדים והמשמרות
לאחר האתחול, תתבקש להזין פקודה מדויקת באנגלית כדי להיכנס לאחד מארבעת תחומי הניהול או לצאת:
`Enter command 1) 'workers' 2) 'jobs' 3) 'placement' 4) 'canidate' 5) 'exit'`

### 3. מדריך הפקודות לפי שירותים

#### 3.1 ניהול עובדים ונהגים (פקודה: `workers`)
תפריט זה מיועד להקמה, הסרה, צפייה ועריכה של כרטיסי העובדים והנהגים בארגון. הפקודות הזמינות בתפריט פנימי זה הן:

| פקודה להקלדה | מה הפעולה מבצעת? | נתונים שתידרש להזין בהמשך |
| :--- | :--- | :--- |
| **`add`** | הוספת עובד כללי חדש למערכת | שם, תעודת זהות (ID), חשבון בנק, שכר, תנאי שכר, תאריך תחילת עבודה (YYYY-MM-DD), האם מוסמך כמנהל משמרת (true/false) |
| **`add driver`** | הוספת נהג חדש למערכת | כל פרטי העובד הכללי + מספר רישיון נהיגה |
| **`remove`** | מחיקת עובד לחלוטין מהמערכת | מזהה עובד (ID) |
| **`view`** | הצגת רשימת כל העובדים במערכת | אין (מציג פלט מרוכז) |
| **`edit`** | עריכת שדה ספציפי של עובד קיים | מזהה עובד, ולאחר מכן בחירת השדה (name, bank account, salary, salary condition, date, shift manager) |
| **`return`** | חזרה לתפריט הראשי | אין |

#### 3.2 תקני משרות במשמרת (פקודה: `jobs`)
תפריט זה מגדיר כמה עובדים ומאילו תפקידים נדרשים עבור משמרת מסוימת במיקום נבחר:
* **`add`**: הוספת דרישת משרה למשמרת. יש להזין תאריך, סוג משמרת (בוקר true, ערב false), בחירת מיקום, וקוד משרה (0 לקופאי, 1 למחסנאי/מוכרן, 2 לנהג).
* **`remove`**: ביטול משרה נדרשת מתקן המשמרת לפי קוד המשרה (0, 1 או 2).
* **`edit`**: החלפת סוג משרה נדרשת בתקן (לדוגמה, שינוי הצורך מקופאי 0 למחסנאי 1).
* **`view`**: הצגת כלל תקני המשרות שהוגדרו עבור המשמרת.
* **`return`**: חזרה לתפריט הראשי.

#### 3.3 מועמדים ואילוצי זמינות (פקודה: `canidate`)
תפריט זה מנהל את זמינות העובדים (מי יכול או מעוניין לעבוד בכל משמרת):
* **`add`**: סימון עובד (לפי ID) כזמין ומועמד לעבודה במשמרת מסוימת במיקום שנבחר.
* **`remove`**: הסרת עובד מרשימת המועמדים והזמינות של המשמרת.
* **`view`**: הצגת רשימת כל העובדים שהגישו מועמדות למשמרת זו.
* **`return`**: חזרה לתפריט הראשי.

#### 3.4 שיבוץ משמרות בפועל (פקודה: `placement`)
תפריט זה מבצע את הציוות המעשי של עובדים ומנהלים לתוך תקני המשמרות הפתוחים:
* **`add`**: יצירת שיבוץ מלא למשמרת.
  * *שלב א':* הזנת תאריך, סוג משמרת, בחירת מיקום ו-ID של מנהל המשמרת.
  * *שלב ב':* ייפתח תפריט הזנה קבוע. יש להקיש `add` כדי להוסיף עובד (להזין ID שלו וקוד תפקיד: 0, 1 או 2). יש לחזור על הפעולה לכל עובד, ולסיום ושמירת המשמרת יש להקיש `stop`.
* **`change`**: החלפת עובד משובץ בעובד אחר במשמרת קיימת (הזנת ה-ID של העובד שיש להסיר וה-ID של העובד החדש שיש לשבץ במקומו).
* **`view`**: הצגת דוח השיבוץ הסופי של המשמרת (מזהה המנהל ורשימת העובדים והתפקידים).
* **`return`**: חזרה לתפריט הראשי.

### 4. חוקים ודגשים קריטיים להזנת נתונים
* **זיהוי משמרת:** כל פעולה (מלבד ניהול עובדים כללי) תבקש זיהוי משמרת המורכב מ-3 נתונים: תאריך, סוג משמרת ומיקום.
* **פורמט תאריך קשיח:** יש להזין תאריכים אך ורק במבנה קשיח של: `YYYY-MM-DD` (לדוגמה: `2026-06-25`). הזנה בפורמט אחר תגרום לשגיאה ותחזיר אותך לתחילת התפריט.
* **סוג משמרת:** יש להקיש `true` עבור משמרת בוקר, או `false` עבור משמרת ערב.
* **קודי תפקידים:** `0` = קופאי (`Casheer`), `1` = מחסנאי/מוכרן (`Shop Keeper`), `2` = נהג (`Driver`).
* **בחירת מיקום:** המערכת תציג אוטומטית רשימה של מזהי מיקומים זמינים (`Location IDs`) לבחירה, ויש להקיש את מספר ה-ID המתאים מתוך הרשימה.

* **הוספת סניף:** הזנת מיקום חדש במערכת המוגדר כסניף קצה לקבלת סחורה. מנוהל על ידי `BranchService` ומתבסס על שכבת המיקומים הכללית.
* **הוספת משאית:** רישום משאית חדשה במערכת דרך `TruckService`, תוך הגדרת מספר הרישוי שלה, משקלה העצמי, והמשקל המרבי המותר שלה לנשיאה כוללת.

#### ב. הזנת ספקים וניהול בקשות משלוח

* **בקשת משלוח:** כאשר סניף מסוים זקוק לסחורה, נוצרת בקשת משלוח חדשה המכילה פירוט כמויות ומוצרים מבוקשים, המוזנת למערכת דרך `RequestService`.
